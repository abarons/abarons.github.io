# abarons Portfolio

Personal portfolio built with Jekyll and published on GitHub Pages.

## Overview

This project is a single-page personal website for showcasing:

- professional experience
- skills and technical stack
- certifications
- education
- projects
- contact information

The site uses a custom dark theme, a sticky sidebar navigation, and data-driven skill sections managed through CSV files.

## Tech Stack

- Jekyll
- GitHub Pages
- Liquid templates
- Ruby / Bundler
- CSV data files

## Local Development

### Prerequisites

Install Ruby and Bundler if they are not already installed.

### Install dependencies

```bash
bundle install
```

### Run locally

```bash
bundle exec jekyll serve --host 127.0.0.1
```

Then open:

```text
http://127.0.0.1:4000
```

### Build site

```bash
bundle exec jekyll build
```

This generates the static website into the `_site` folder.

## GitHub Pages Deployment

This repository is intended to be published via GitHub Pages.

### Recommended branch strategy

- `main`: source code and content development
- `gh-pages`: deployed static website used by GitHub Pages


## Skills Data

Skills are stored in CSV format under:

```text
_data/skills.csv
```

The CSV includes fields such as:

- order
- category
- name
- years
- level
- description

This makes it easy to maintain and update technical skills without modifying the HTML template.

## Customization

To update the site content:

- edit the sections in `index.markdown`
- update the CSV file in `_data/skills.csv`
- modify the styling in `assets/css/portfolio.css`
- adjust the layout in `_layouts/home.html`
