# abarons Portfolio

Personal portfolio built with Jekyll and published on GitHub Pages.

## Overview

This project is a single-page personal website for showcasing:

- professional experience
- skills and technical stack
- certifications
- education
- projects
- contact information

The site uses a custom dark theme, a sticky sidebar navigation, and data-driven sections managed through Liquid templates and CSV files.

## Security hardening

The portfolio follows safer static-site practices:

- applies a Content Security Policy (CSP) and Referrer Policy using HTML meta tags
- removed external dependencies such as Google Fonts
- moved JavaScript logic out of inline HTML into a dedicated file
- replaced inline style attributes with CSS classes
- added a security disclosure file at `.well-known/security.txt`

GitHub Pages branch-based hosting does not let this repository set arbitrary HTTP response headers. As a result, policies that
must be sent as HTTP headers (such as `X-Content-Type-Options`, `Permissions-Policy`, and CSP `frame-ancestors`) are not enabled
by this site. The CSP uses directives supported by an HTML meta policy.

## Local Development

### Prerequisites

Install Ruby and Bundler if they are not already installed.

### Install dependencies

```bash
bundle install
```

### Run locally

```bash
bundle exec jekyll serve --host 127.0.0.1
```

Then open:

```text
http://127.0.0.1:4000
```

### Build site

```bash
bundle exec jekyll build
```

This generates the static website into the `_site` folder.

## GitHub Pages Deployment

The `main` branch is both the source and deployment branch. The repository is the user site `abarons.github.io`, so the site is
published from the root of the branch and `_config.yml` correctly uses an empty `baseurl`.

To configure or verify publishing in GitHub:

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Push changes to `main`; GitHub Pages builds and publishes the site.

The generated `_site` directory is only for local builds and is ignored by Git; do not commit it for this publishing method.

## Skills Data

Skills are stored in CSV format under:

```text
_data/skills.csv
```

The CSV includes fields such as:

- order
- category
- name
- years
- level
- description

This makes it easy to maintain and update technical skills without modifying the HTML template.

## Customization

To update the site content:

- edit the sections in `index.markdown`
- update the CSV file in `_data/skills.csv`
- modify the styling in `assets/css/portfolio.css`
- adjust the layout in `_layouts/home.html`
- add or update logic in `assets/js/site.js`

## Security notes

This site is a static portfolio and does not expose login, APIs, or user-generated content. The hardening efforts are focused on improving browser-level protections and reducing external runtime dependencies.
